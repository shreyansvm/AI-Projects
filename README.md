# AI Projects

A collection of personal projects built with AI assistance.

## Projects

### [Reclist](./reclist)
A personal wishlist for recommendations from people you trust — movies, restaurants, parks, museums, and anything else. Captures who recommended it, what they said, and keeps everything in one place.

**Stack:** Next.js 16 · Tailwind CSS v4 · NextAuth v5 · SQLite (Drizzle ORM)

**Docs:** [Problem Definition](./reclist/docs/Problem%20Definition.md) · [Design](./reclist/docs/Design.md) · [Spec](./reclist/docs/Reclist%20Spec.html)
